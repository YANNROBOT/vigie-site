# Le site de Vigie

Le site de présentation de **Vigie**, la veille réglementaire et la file de publication des cabinets, conçue par Deilex Audit & Conseils (Abidjan).

Ces pages sont **fabriquées** par `outils/fabriquer_site.py`, dans le dépôt du logiciel : on ne les modifie pas ici, on les régénère là-bas puis on les publie.

L'installateur Windows se télécharge depuis les [versions](../../releases/latest) de ce dépôt.
